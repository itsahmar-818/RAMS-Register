KIRAYA REGISTER — install karne ka tareeqa
==========================================

Is folder ki SAARI files GitHub par upload karni hain, bilkul waise hi
jaise Bijli wale repo mein ki thin.

1. GitHub par naya repo banayein, naam rakhein: Kiraya
2. Is zip ki saari 7 files us repo mein upload karein.
   Kisi folder ke andar nahi — seedha repo ki jar (root) mein.
3. Repo ki Settings > Pages kholein.
   Source: "Deploy from a branch", Branch: main, Folder: / (root). Save.
4. Do teen minute baad yeh link chalne lagega:
   https://itsahmar-818.github.io/Kiraya/
5. Woh link phone ke Chrome mein kholein.
   Menu (teen nuqte) > "Install app" ya "Add to Home screen".

Ab icon par Chrome ka chhota nishaan NAHI aayega, aur app internet
band hone par bhi khulegi.

Files:
  index.html               poori app
  manifest.webmanifest     app ka naam, icon aur standalone mode
  sw.js                    offline chalane ke liye
  icon-192.png             chhota icon
  icon-512.png             bara icon
  icon-512-maskable.png    Android ke gol/square frame ke liye
  apple-touch-icon.png     iPhone ke liye

Data aap ke phone mein rehta hai, kisi server par nahi jata.
Mahine mein ek dafa app ke Backup tab se text copy karke apne aap ko
WhatsApp kar lein.
